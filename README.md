# Автотесты для демо-проекта saucedemo.com

## Вступление

Автотесты для тестирования функциональности фронтендf демо-проекта SauceDemo с использованием Playwright и TypeScript.

## Установка и запуск текстов

- `npm install` - установка зависимостей
- `npm test` - запуск всех тестов
- `npx playwright test --ui` - запуск тестов с интерфейсом Playwright
- `npx playwright show-repor` - просмотр HTML-отчёта

## В проекте реализованы тесты основных пользовательских сценариев

- авторизация
- работа с каталогом товаров и сортировкой
- добавление и удаление товаров из корзины
- работа с боковым меню
- оформление заказа
- валидация формы пользовательских данных
- проверка итогового заказа
- завершение заказа и скачивание PDF
- проверка ссылок на социальные сети

## Используемые технологии

- [Playwright](https://playwright.dev/) - фреймворк для автоматизированного end-to-end тестирования веб-приложений
- [ESLint](https://eslint.org/) - это инструмент статического анализа кода для поиска и исправления проблем в JavaScript, JSX и других связанных языках
- [Prettier](https://prettier.io/) - это инструмент для автоматического форматирования исходного кода
- [TypeScript](https://www.typescriptlang.org/) - язык программирования, представляющий собой надстройку над JavaScript, которая добавляет в него статическую типизацию и другие полезные возможности
- [GitHub Actions](https://github.com/features/actions) - автоматический запуск автотестов в CI
